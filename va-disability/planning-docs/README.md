# planning-docs/

Internal plans, strategies, checklists, worklists, and prep guides for the VA
disability claim. Per `CLAIM-MASTER-BRIEF.md` §2.6, **nothing in this folder is
evidence and nothing here is ever submitted to VA** — it is for the veteran's and
the VSO's use only.

Current working docs (2026-10-18): **`STRATEGY-TO-100-2026-10-18.md`** (governing
100% strategy — corrects the invalid "90% MH" route math in the older docs) and
**`cp-exam/`** (C&P exam prep for 21 Oct 2026). Still useful for evidence work, with
corrected odds: `CLAIM-MASTER-BRIEF.md`, `PATH-TO-100-PERCENT-2026-07-07.md` +
`ACTION-CHECKLIST-100-PERCENT.md`, `MASTER-STRATEGY.md`. `strategy.md`, `CLAIM-EXECUTION-PLAN.md`, and
`DO-THIS-WEEK.md` are superseded, kept for history. See `../REPORT.md` "Start
here" for the live index.
