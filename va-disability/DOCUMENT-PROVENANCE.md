# Document Provenance Log

> **Purpose:** track the actual origin of every claim-facing document in this corpus —
> who wrote the substantive content, how much AI involvement there was, and current
> status. This exists because a 2026-07-06 session found a document presented as
> independently authored that was byte-identical to a separately-documented AI-
> reconstructed draft, and nothing in this corpus tracked provenance to catch that. For
> witness statements specifically, provenance is exactly what a rater or opposing party
> would probe if credibility is ever challenged — a cheap log beats reconstructing this
> from memory under pressure later.
>
> **Maintained by:** `va-corpus-sync` skill logs a new row whenever a claim-facing
> document is added or reaches "final" status. Add rows by hand too if that skill isn't
> used for a given document.
>
> **Origin categories:**
>
> - `self-authored` — the declarant wrote it from a blank page, no AI/third-party draft
>   involved.
> - `ai-drafted-then-revised` — an AI produced a first draft, the declarant edited it.
> - `ai-extracted-from-source` — an AI pulled true content out of a longer source (e.g.
>   an email chain), filtering out anything coached/reframed, then the declarant reviewed.
> - `mixed` — some combination not cleanly captured above; explain in Notes.
> - `unknown — confirm` — provenance hasn't been established; don't assume either way.
